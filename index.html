    Com o editor instalado no seu site, o botão Publicar envia o arquivo ao GitHub por você, sem baixar nada. O passo a passo está no guia.

    1. No GitHub, abra o repositório do site.
    2. Toque em Add file e depois em Upload files.
    3. Envie este index.html com o mesmo nome e confirme em Commit changes.
    4. Se usou vídeos ou imagens por caminho, envie esses arquivos também, na mesma pasta indicada.
    5. O Vercel publica a nova versão sozinho em alguns segundos.
